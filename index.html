// NUMBER GUESSING SURVIVAL

名前を入力してルームを作るか、6桁コードで参加しましょう。

ルーム作成時、6桁のコードは自動で発行されます。登録不要・同じ端末の別タブでは同一参加者として扱われます。

GAME RULE

相手の数字を推理し、最後の1人まで生き残れ。

  1. 参加人数 × 20 を上限に、秘密の数字を1つ選ぶ。
  2. サイコロの出目が大きい順に手番を決める。
  3. 相手を1人指名し、その人の数字を予想する。
  4. 相手は「ハイ」「ロー」「正解」で回答する。
  5. 数字を当てられた人は脱落する。
  6. 4周終了後、脱落者がいたら次セットの数字上限が半減する。
⚄⚂
♛ 最後まで生き残った人が優勝！

数字の重複・再使用はOK。セット終了時に全員が数字を選び直す。最後の1人になった時点で即終了。
